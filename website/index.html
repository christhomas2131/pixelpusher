FAQ
Common questions
Does PixelPusher send my photos anywhere?
No. Everything runs locally on your machine. No analytics, no telemetry, no cloud. Your photos never leave your computer.
How many files can it handle?
Tested with 40,000+ files. All data is stored in a local SQLite database — memory usage stays flat regardless of library size.
Will it delete my originals?
No. The default operation is Copy — originals stay exactly where they are. Move mode is available but explicit and optional. PixelPusher never auto-deletes anything.
Why does Windows SmartScreen warn about it?
SmartScreen warns about any new unsigned app. PixelPusher is not signed yet (that costs $300/year). Click "More Info → Run Anyway" to proceed. The source code is fully open.
What file formats are supported?
Images: JPG, PNG, HEIC, WEBP, TIFF, GIF, BMP. Videos: MP4, MOV, AVI, MKV, M4V, WMV. RAW: CR2, CR3, NEF, ARW, ORF, RW2, DNG, RAF, PEF.
