# Reporting Bugs and Requesting Features

PixelPusher is proprietary software, so external code contributions are not currently accepted. However, bug reports and feature requests are very welcome.

## Reporting a Bug

1. Search [existing issues](https://github.com/christhomas2131/pixelpusher/issues) first to see if someone already reported it.
2. If not, [open a new issue](https://github.com/christhomas2131/pixelpusher/issues/new).
3. Include:
   - **Windows version** (10 or 11, 64-bit or 32-bit)
   - **PixelPusher version** (Help > About menu)
   - **What you were doing** when the bug happened
   - **What you expected** to happen
   - **What actually happened**
   - **The log file** from `%USERPROFILE%\.photomove\logs\` — drag and drop it onto the issue

Logs make bug fixing about 10x faster. Please attach them.

## Requesting a Feature

Open an issue with the title prefixed `[Feature Request]`. Describe:
- What you want to do
- Why you want to do it
- How you imagine it working

## Security Issues

If you find a security vulnerability, please do NOT open a public issue. Email the details to christhomas2131@gmail.com instead.
